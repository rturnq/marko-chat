# Marko Chat

Chat app MPA: a stub on [Marko 6](https://markojs.com) and [Marko Run](https://markojs.com/docs/marko-run/getting-started/).

The stub is a single page: an in-memory message list and a `<form method="post">` that appends a message and
redirects back (no client JS).

## Run locally

```bash
pnpm install
pnpm dev
```

```bash
pnpm typecheck
pnpm build
pnpm preview
```
